# What Can AI Do?

一份**活的使用手册**：20 个场景，告诉你今天免费就能用的 AI 能干什么、怎么开口、哪里别信。每个案例都有一条可以直接复制就能用的提示词。

> ⚠️ 诚实声明：这些案例由 AI 依据产品公开能力整理成稿，**大部分尚未经真人逐步实测**；提示词可直接抄用，但具体按钮/入口以产品当前版本为准。你跑通了（或跑不通）都请告诉我们——这正是本站需要读者的原因。

我们从「手机上问 AI」讲起，一路讲到「AI 替你干活」。大多数人现在只用到前一半，后一半才是省时间的地方。

**线上版本**：<https://what-can-ai-do.pages.dev/>

## 这是什么

- **公益项目**：案例、教程、提示词都不收钱，以后也不打算卖课
- **热度驱动**：案例从真实需求与公开讨论的高频痛点出发，按统一模板整理；多数案例尚在验证中，欢迎反馈修正
- **提示词原文化**：每个案例的提示词都可以一键复制，替换花括号就能用

## 案例（20 个）

锚点入门 → 日常对话 → 创作与分发 → **agent 密集区**（分步执行、审批、监控）→ 技术进阶 → 风险防线（识破 AI 诈骗、AI 炒股红线）

## 参与

- **提反馈 / 投稿案例**：你用 AI 干成过什么事？验证通过后会上墙 → 见站点「关于」页
- **Issue**：案例错误、建议、Bug 都欢迎
- **PR**：修错别字、补案例、改代码皆可

入选标准：免费能做、多数人用得上、你真的做过一次。

## 本地运行

```sh
npm install
npm run dev      # localhost:4321
npm run build    # 产物在 dist/
```

## 部署前检查

```sh
node scripts/check.cjs http://localhost:4321   # 结构/链接/图标/溢出全量检查
python3 scripts/align_check.py <截图路径>        # 图标-文字对齐像素级检查
```
