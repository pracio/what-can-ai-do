# What Can AI Do?

一份**活的使用手册**：20 个真实场景，告诉你今天免费就能用的 AI 能干什么、怎么开口、哪里别信。每个案例都有一条可以直接复制就能用的提示词。

我们从「手机上问 AI」讲起，一路讲到「AI 替你干活」——这是这一代 AI 最重要的分水岭。

**线上版本**：<https://what-can-ai-do.pages.dev/>

## 这是什么

- **公益项目**：所有案例、教程、提示词永远免费，不设付费墙、不卖课
- **热度驱动**：案例从真实需求出发，经实测后收录
- **提示词原文化**：每个案例的提示词都可以一键复制，替换花括号就能用

## 案例（20 个）

锚点入门 → 日常对话 → 创作与分发 → **agent 密集区**（分步执行、审批、监控）→ 技术进阶 → 风险防线（识破 AI 诈骗、AI 炒股红线）

## 参与

- **提反馈 / 投稿案例**：你用 AI 干成过什么事？实测后会上墙 → 见站点「关于」页
- **Issue**：案例错误、建议、Bug 都欢迎
- **PR**：修错别字、补案例、改代码皆可

入选标准：免费能做、多数人用得上、你真的做过一次。

## 本地运行

```sh
npm install
npm run dev      # localhost:4321
npm run build    # 产物在 dist/
```

## 部署前检查

```sh
node scripts/check.cjs http://localhost:4321   # 结构/链接/图标/溢出全量检查
python3 scripts/align_check.py <截图路径>        # 图标-文字对齐像素级检查
```
