# 讓 AI 幫你做研究

**能做什麼**：這是從「問答 AI」跨到「幹活 AI」的那一步。你不用再開二十個分頁——深度研究模式會自己跑好幾分鐘，搜尋、閱讀、交叉比對，最後給你一份帶來源的結構化報告。你出題目，它跑腿。
**要多久**：5–15 分鐘（它跑的時候你可以去做別的事）。**要花錢嗎**：免費額度每月有次數限制，付費版較多。

|---|---|---|
| ★★☆☆☆ 講清楚要什麼 | ★★☆☆☆ 找到深度研究入口 | ★★☆☆☆ 大決策先核對 |

## 怎麼做

### 用 [ChatGPT](https://chatgpt.com/) 的深度研究（或 [Google Gemini](https://gemini.google.com/) 的同名功能）

1. 開新對話，在輸入框旁的工具選單找到**深度研究**（Deep Research）。一般對話不會自己上網多步查證——這個模式才是讓它變成 agent 的開關
2. 把這段話傳給 AI（換成你的主題）：

> 幫我研究「我想買的手機」：先拆解成 3-5 個關鍵問題，逐一上網查證，最後給我一份報告——結論放最前面，中間列出不同來源的說法和分歧，結尾註明資訊的時效性。

3. 它跑的時候你會看到它在搜尋、在讀資料——這時候去忙你的，回來就是一份報告
4. 一定要問那句追問：**「這個結論的來源可靠嗎」**——它會告訴你哪些說法有紮實來源、哪些薄弱

### 適合用 vs. 不適合用

**適合**：買大件前比價幾十篇評測、進入一個陌生領域的入門功課、重大決定的背景調查（「要搬去某城市，學區要注意什麼」）、把一團亂的新聞事件理出頭緒

**不適合**：錯了代價很高的判斷。一份讀起來很有信心的報告，來源可能很薄弱——醫療、法律、財務的題目，上面那句追問不是選配，是必經流程

### 注意

- **「深度研究」不等於正確。**它像一個勤快的實習生在查資料，不是領域專家在下判斷。重大決策，報告要再給懂的人看一眼
- **免費額度有限**：各家對免費帳號的深度研究都是每月計次。把次數留給真正需要多步查證的問題，簡單問題用一般對話就好
- **資訊有時效**：來源可能是幾年前的舊資料。提示詞已經要求它註明時效——那行字要看
