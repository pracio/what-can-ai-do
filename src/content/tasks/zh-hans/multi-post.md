# 一稿多发：写一次，铺满各平台

**能做什么**：同一篇内容要发公众号、知乎、小红书、头条？每个平台格式、语气、字数要求都不同。agent 能把"改写成 N 个平台版本"到"按平台要求排版"整套做完，你只审稿。
**要多久**：AI 干 15-30 分钟。**要花钱吗**：免费。
**为什么是 agent 活**：不是一次问答能完成的——要拆任务（逐平台改写）、守规则（每平台规范不同）、多步执行（排版+预览），这正是 agent 和 chatbot 的分界线。

## 怎么做

### 用 [WorkBuddy](https://www.workbuddy.cn/)（电脑）

1. [下载安装 WorkBuddy](https://www.workbuddy.cn/)，把原稿存成一个文件，授权给它的文件夹，发这段话：

> 这个文件夹里有我的原始文章。请把它改写成多平台版本：1) 公众号版（段落短、有钩子开头）；2) 知乎版（逻辑链完整、可长）；3) 小红书版（300 字内、口语化、给 5 个标签）；4) 头条版（标题党一点但别失实）。每个版本单独存一个文件，改写时保留我的核心观点和事实，别加我没说过的案例。完成后给我一个对照表：各版本差异在哪。

2. 逐个审稿——重点看它有没有"为了平台感"篡改你的事实

3. 发布还是你自己点（各平台登录状态在你手里），它负责让每一版都是"_native"的

## 做不好的

- 完全自动发布（替你点发送）技术上可行但风险高——发错平台/带格式错误，建议发布动作自己来
- 图片需要各平台单独配，它改文不管图（可让它给配图建议）
- 违规词检测不可靠，敏感领域内容自己把过关

## 防坑提示

- 让它"保留核心观点"要写进提示词，否则它会为了流量改你的立场
- 各平台对"AI 生成内容"有标注要求，如实勾选
